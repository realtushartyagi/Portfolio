# Portfolio

This is a personal portfolio project built using React and TypeScript. It showcases your skills, projects, and achievements in a modern and interactive way.

## Features

- Built with React and TypeScript
- Responsive design using Bootstrap
- Routing with React Router
- Interactive components with React Icons, Parallax Tilt, and Typewriter Effect
- PDF rendering and GitHub calendar integration
- Modern UI/UX

## Getting Started

### Prerequisites

- Node.js (>=14.x)
- npm (>=6.x)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/realtushartyagi/Portfolio.git
   cd Portfolio
   ```
2. Install dependencies:
   ```bash
   npm install
   ```

### Running Locally

```bash
npm start
```

Open [http://localhost:3000](http://localhost:3000) to view the app in your browser.

### Building for Production

```bash
npm run build
```

## Folder Structure

- `src/` - Source code for components and pages
- `public/` - Static assets
- `main.tsx` - Main entry point
- `Home2.css` - Custom styles

## Dependencies

- React, React DOM, React Router DOM
- Bootstrap, React Bootstrap
- React Icons, React Parallax Tilt, Typewriter Effect
- React PDF, React GitHub Calendar, React Tsparticles
- Axios (for HTTP requests)

See `package.json` for the full list.
